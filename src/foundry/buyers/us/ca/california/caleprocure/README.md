# Cal eProcure California State Contracts Register

Scope is the default **Posted** result list at
`https://caleprocure.ca.gov/pages/Events-BS3/event-search.aspx`. It includes state
agencies, universities, fairs, and other departments listed on that page. It does
not include historical events unless the portal changes its default filter.

The browser posts to `/nlx3/psc/psfpd1/SUPPLIER/ERP/c/AUC_MANAGE_BIDS.AUC_RESP_INQ_AUC.GBL`.
InFlight projects the underlying PeopleSoft HTML into JSON with client-provided
capture selectors. The spider reads that source HTML at `/psc/psfpd1/...` instead;
it includes the department IDs which the browser hides from the search table.
The initial response contained all 385 events (`1-385 of 385`). Search pagination
is also followed when present, with a check against the reported total.

Each detail GET uses `AUC_MANAGE_BIDS.AUC_RESP_INQ_DTL.GBL` with the event and
business-unit IDs. Omitting `AUC_VERSION` selects the current version. A form
POST with `ICAction=RESP_INQ_DL0_WK_AUC_DOWNLOAD_PB` opens its package, and
`PV_ATTACH_WRK_SCM_DOWNLOAD$N` resolves each attachment into a file URL.
The tested server accepts `ICAction` in both query and form, giving every POST
a distinct fixture URL. Hidden state and CSRF fields come from the preceding
response. Two independent PeopleSoft windows process events concurrently;
actions within each window run sequentially so their server state cannot mix.

Deadlines are labeled PDT/PST. Server HTML can use either `MM/DD/YYYY` or
`YYYY/MM/DD` depending on the guest session's locale. Both are interpreted in
`America/Los_Angeles`, including daylight saving time.

File URLs are generated by PeopleSoft and require the current guest session.
`/viewredirect/` is the download link used by the browser; a fresh link was
verified with Foundry's plain HTTP headers, Referer, and browser session cookies
as a 200 PDF beginning `%PDF`. The same links later returned 404 within minutes, while freshly resolved links
still returned PDFs. Each crawl resolves new links, but early links can expire
before Foundry downloads files after a large crawl. No stable stateless download
endpoint was found; this is an explicit handoff limitation.

Fixtures contain the entry page, one complete search response, and all detail,
package and download-link responses for `2740/26-134` and `SS246/0000040527`.
Transport cookies and hidden session identifiers are removed. File bytes are
not included.

Verification on 2026-10-22: the rendered page showed 385 rows with Posted selected;
the full live crawl printed PASS with 385 valid listings, zero invalid listings,
and zero crashes, resolving 1,191 attachment links. All titles and deadlines
matched the search rows. Fixture replay was healthy with two complete listings.
